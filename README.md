# Trade Analyzer desktop distribution

Binaries, native update metadata and customer-authored notes only. Product source stays private.

Internal builds, source tags and version bumps do not approve customer releases. Candidates remain drafts until the release owner explicitly promotes a complete production-signed and independently validated candidate.

Automatic updates: macOS Apple Silicon and Windows x64. Initial installers do not grant access; the existing Trade Analyzer license remains required. Installed MT5 EAs, extensions and hosted services are not updated by the desktop updater.

No customer release has been promoted by the updater implementation task.
